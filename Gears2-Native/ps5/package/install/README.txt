Gears of War 2 for PS5 - put your game files here.

  /data/homebrew/<this app's folder>/install/

What goes in this folder (any file names, sub-folders are looked through too):

  1. Your own Gears of War 2 Xbox 360 disc, as an .iso: the US disc
     (game version 0.0.0.5), the one COGBox's PC port is made for.
  2. Gears of War 2 Title Update 6 for that disc, the package file as it is
     (no extension), from the console's drive:
       Content/0000000000000000/4D53082D/000B0000/
     There can be more than one Title Update 6 file there (for different
     builds of the disc); copy them all if you aren't sure, and the app takes
     the right one.
  3. Optional: Gears of War 2 DLC packages from your Xbox 360
     (Content/0000000000000000/4D53082D/00000002/ on its drive).

Then start the app. The first start checks the files against the ones this
build was made from and gets the game ready: the title update (and any DLC)
is unpacked. The screen says how far it is. If the app is closed meanwhile,
the next start goes on from there. The disc image has to stay here: the game
reads its data straight from it. When it is done, the screen offers to delete
the packages the game no longer needs (Cross deletes them, Circle keeps them).
Later starts go straight to the game, as long as this folder holds the same
files.

If something is missing or isn't the right release, the app says so on screen.

No game files come with this app: you need your own copy of the game.
